# Float Friends 开放用户自定义 AI API

## 用户需求

- 恢复作者原本提供的 AI API 配置入口。
- 用户可以填写自己的供应商、Base URL、API Key 和模型。
- 平台 AI 继续保留为开箱即用的默认与兜底。
- 用户选择自己的配置后，登录、刷新、云恢复不得自动切回平台 AI。

## 根因

- 作者原版具备完整 API 设置页和配置绑定系统。
- Friends 版上一阶段为了降低首次使用门槛，主动隐藏了 API 设置入口。
- `AccountCloudBootstrap` 每次登录都会把全局默认绑定重写为 `platform-managed`，即使重新显示入口，用户选择也会被覆盖。

## 关键决策

1. 恢复设置首页的“API 设置”。
2. `platform-managed` 永远存在、不可编辑、不可删除，作为平台兜底。
3. API 配置卡明确显示当前生效项，并提供“设为当前”。
4. 新增配置后由用户显式选择，不在未测试时自动切换。
5. 删除当前自定义配置时自动回到平台 AI。
6. 启动初始化仅在当前绑定无效或为空时选择平台 AI；有效的用户配置保持不变。
7. 自定义配置继续进入账号云备份，供同账号跨设备恢复。

## 验收标准

- 设置首页能看到“API 设置”。
- 平台 AI 卡片可选择但不能编辑或删除。
- 用户可以新增、编辑、拉取模型并测试连接。
- “设为当前”后全局绑定立即指向用户配置。
- 刷新页面后仍保持用户选择。
- 删除当前配置后回退平台 AI。
- 平台模型与自定义模型均能完成一次真实调用。
